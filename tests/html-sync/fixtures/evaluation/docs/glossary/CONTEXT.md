# Ordering

Tracks customer orders.

## Terms

**Order**:
A customer's request for goods.

_Avoid_: Purchase, transaction

**Backorder**:
An order that ships only after stock returns. Do not accept a backorder without the owner's approval.

_Avoid_: Waitlist

**Cancellation**:
An order may be cancelled before shipment. After shipment, only the owner may approve a return.

_Avoid_: Refund
